# Arabic Hitster - Project Plan

A mobile guessing game inspired by Hitster, focused on Arabic music (mostly 80s and 90s). Players listen to a short preview of a song and try to guess its name before revealing the answer.

---

## Architecture (MVP - No Backend)

```
┌──────────────────┐         Spotify CDN
│   Mobile App      │─play──▶ (preview MP3s)
│  (Expo/RN)        │
│  reads tracks.json│         ┌──────────────┐
│  (bundled/remote)  │         │  Later: add   │
└──────────────────┘          │  Backend API  │
                               │  → Spotify   │
                               └──────────────┘
```

**No backend needed for MVP.** The app bundles a `tracks.json` file extracted once from the playlist. Spotify preview URLs are public MP3s on Spotify's CDN, so no authentication is needed to play them.

### Upgrade Path (Later)

When dynamic playlist loading is desired:

1. Add `backend/` with Spotify Client Credentials auth
2. Change `DATA_SOURCE` in `constants.ts` from `'local'` to `'api'`
3. Deploy backend to Railway
4. Add GitHub Actions workflow for backend deploy
5. App code stays the same - same Track interface, same hooks

## App Flow (Screens)

1. **Home Screen** - App title/logo, "Start Game" button, settings icon
2. **Game Screen** - Two states:
   - **Playing**: Audio plays, animated waveform/indicator, "Reveal" button
   - **Revealed**: Shows song name, artist, album art, year. "Next Song" button

---

## Game Logic

- On start, load tracks from `tracks.json`
- Shuffle the track list
- Play a random track's `preview_url`
- Track which songs have been played (avoid repeats until all exhausted)
- On "Reveal": show song details, pause or let audio finish
- On "Next": pick next unplayed track, play its preview

## Key Configuration

`app/src/constants.ts`:

```ts
export const SPOTIFY_PLAYLIST_ID = '37i9dQZF1DXaHuo0R6jTxZ';
export const DATA_SOURCE: 'local' | 'api' = 'local'; // swap to 'api' when backend is added
export const API_BASE_URL = __DEV__
  ? 'http://localhost:3000'
  : 'https://your-backend-url.com';
```

The `SPOTIFY_PLAYLIST_ID` is the only variable that needs changing to switch to a different playlist. When upgrading to dynamic loading, `DATA_SOURCE` is flipped from `'local'` to `'api'`.

## Track Extraction Script

`scripts/extract-tracks.js` is a one-time script that:

1. Authenticates with Spotify using Client Credentials
2. Fetches all tracks from the configured playlist (handling pagination)
3. Filters out tracks without `preview_url` (some songs lack previews)
4. Saves the result as `data/tracks.json`

To run it:

```bash
cd scripts
SPOTIFY_CLIENT_ID=xxx SPOTIFY_CLIENT_SECRET=yyy node extract-tracks.js
```

> Note: This script only needs to run when you want to refresh the playlist data. For the MVP, the extracted data is bundled with the app.

## Spotify Developer Setup (For Extraction Script Only)

The main app does not need Spotify Developer credentials. This is only needed to run the `extract-tracks.js` script to refresh `tracks.json`.

1. Go to [Spotify Developer Dashboard](https://developer.spotify.com/dashboard)
2. Click "Create an app"
   - If you cannot create a new one, use an existing app
3. Copy **Client ID** and **Client Secret** from Settings
4. Run the extraction script with those credentials

### Redirect URI Note

The Client Credentials flow does not use redirect URIs at all. The "This redirect URI is not secure" error only affects OAuth flows (Authorization Code, PKCE). If you already have a working app with Client ID and Secret, you can use those credentials directly - no redirect URI configuration needed.

## Mobile App Setup

### Testing on Your Phone (No Apple Account Needed)

Install **Expo Go** from the App Store (iOS) or Play Store (Android):

```bash
cd app
npm install
npx expo start
```

Scan the QR code with Expo Go to run the app instantly on your device.

### Building for Distribution

- **Android**: EAS Build produces an APK that can be shared directly
- **iOS**: App Store distribution requires an Apple Developer account ($99/year)
- **iOS (testing only)**: Expo Go works without any Apple account
